# Hop 25 → 27 (via 26)

Non-LTS hop. Only plan it when the user targets 26 or 27. JDK 26 and 27 changes are listed together; a 25 → 27 hop applies both.

Contents: final field mutation · Applet removal · G1 in every environment · compact object headers · hybrid post-quantum TLS · preview API churn · verification.

Signals: `deep-reflection`, `applet`, `preview-flag`, `structured-concurrency-old`.

## Final field mutation warns — JEP 500 (26)

Deep reflection that writes a `final` field (`Field.setAccessible(true)` then `Field.set`) prints a warning on 26. `--illegal-final-field-mutation=warn` is the default; `deny` is planned as a future default.

Typical sources: serialization libraries (old Jackson/Gson/Kryo setups that populate finals), dependency injection into final fields, test utilities that patch `static final` constants, mocking frameworks.

- Find them: run tests with `--illegal-final-field-mutation=debug` (stack trace per mutation) or record the JFR event `jdk.FinalFieldMutation`.
- Fix own code: constructor injection, records or non-final fields; for tests, inject the value instead of patching a constant.
- Libraries: bump them.
- Temporary: `--enable-final-field-mutation=ALL-UNNAMED`, recorded in progress.md.

Deserialization through `java.io.Serializable` and `sun.reflect.ReflectionFactory` is not affected.

## Applet API removed — JEP 504 (26)

`java.applet`, `javax.swing.JApplet`, `java.beans.AppletInitializer` are gone. Convert applets to a `JFrame` application (or drop them):

<!-- compile: jdk=8 -->
```java
import javax.swing.JFrame;
import javax.swing.JLabel;
import javax.swing.SwingUtilities;

static void show() {
    SwingUtilities.invokeLater(() -> {
        JFrame frame = new JFrame("Former applet");
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.add(new JLabel("Hello"));
        frame.pack();
        frame.setVisible(true);
    });
}
```

## G1 in every environment — JEP 523 (27)

Before 27 the JVM picked Serial GC on "small" machines (1 CPU or under 1792 MB). From 27 it always picks G1. Small containers can see slightly higher memory overhead. If a service relied on the old choice, set `-XX:+UseSerialGC` explicitly; otherwise nothing to do. Measure container memory after the switch.

## Compact object headers on by default — JEP 534 (27)

Object headers shrink to 8 bytes (opt-in product feature in 25, JEP 519). Heap use usually drops. Code is unaffected unless it depends on object layout (JOL-based tests, off-heap layouts computed from `Unsafe.objectFieldOffset`, native agents). Opt out with `-XX:-UseCompactObjectHeaders`.

## Hybrid post-quantum key exchange in TLS 1.3 — JEP 527 (27)

`X25519MLKEM768` is the preferred TLS 1.3 named group. The ClientHello gets larger; some middleboxes and old servers mishandle it. If outbound TLS fails only on 27, test with `-Djdk.tls.namedGroups=x25519,secp256r1,…` to confirm, then fix the peer or keep the override documented.

## Preview API churn (26, 27)

Preview APIs changed in both releases; code compiled with `--enable-preview` on 25 must be revisited:

- Structured concurrency: 6th preview in 26, 7th in 27 with API changes (third type parameter, `join()` throws `ExecutionException`, `Joiner.awaitAll()` removed, `timeout()` replaces `onTimeout()`).
- `StableValue` (25) renamed to `LazyConstant` (26); 27 removed `isInitialized` and `orElse`.
- Primitive patterns, PEM encodings: still preview.

Default: replace preview usage with final APIs before this hop and drop `--enable-preview`.

## Other changes

- `Thread.stop()` is removed (absent in JDK 27; it threw since 20). jdeprscan and the compiler flag remaining calls.
- HTTP/3 client available in 26 (opt-in, `HttpClient.Version.HTTP_3`); defaults unchanged.
- AOT object caching works with every GC from 26 (JEP 516); startup tuning only.
- JDK 26 and 27 are not LTS: support ends when the next release ships. Make sure the user knows before targeting them.

## Verification

- Build with `release` 26/27 on that JDK; tests green.
- Run tests once with `--illegal-final-field-mutation=debug` and resolve or record every hit.
- Start the service in its real container size; compare memory and GC logs with the 25 baseline.
- Exercise outbound TLS connections.
