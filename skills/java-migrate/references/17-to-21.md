## UTF-8 by default — JEP 400 (18)

`Charset.defaultCharset()`, `FileReader`, `FileWriter`, `InputStreamReader` without a charset, `Files.newBufferedReader` (already UTF-8) now use UTF-8 on every OS. Before 18 they used the platform encoding (for example windows-1252 on Windows).

Risk: files written by an older version on a non-UTF-8 host are read differently. Rules:

- Pass an explicit charset wherever data crosses a process boundary (files, sockets, process output). Keep existing `StandardCharsets.UTF_8`; do not remove it.
- `System.out` uses `stdout.encoding`, not `file.encoding`.
- `-Dfile.encoding=COMPAT` restores the platform default as a temporary measure for legacy data.

<!-- compile: jdk=11 -->
```java
import java.io.BufferedReader;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;

static String firstLine(Path file) throws IOException {
    try (BufferedReader reader = Files.newBufferedReader(file, StandardCharsets.UTF_8)) {
        return reader.readLine();
    }
}
```

## Finalization deprecated for removal — JEP 421 (18)

`finalize()` overrides compile with a removal warning; finalization can be disabled with `--finalization=disabled` (run the tests with it to find dependencies on finalizers).

Replacement: make the resource `AutoCloseable` and use try-with-resources; for a safety net use `java.lang.ref.Cleaner`. The cleanup action must not reference the owning object.

<!-- compile: jdk=9 fails-below -->
```java
import java.lang.ref.Cleaner;

static final class NativeHandle implements AutoCloseable {
    private static final Cleaner CLEANER = Cleaner.create();

    private static final class Release implements Runnable {
        private final long address;
        Release(long address) { this.address = address; }
        @Override public void run() { free(address); }
    }

    private final Cleaner.Cleanable cleanable;

    NativeHandle(long address) {
        this.cleanable = CLEANER.register(this, new Release(address));
    }

    @Override
    public void close() {
        cleanable.clean();   // runs Release once; the Cleaner is only a fallback
    }

    private static void free(long address) { /* release native memory */ }
}
```

## Thread.stop, suspend, resume (20)

`Thread.stop()`, `suspend()`, `resume()`, `ThreadGroup.stop()` throw `UnsupportedOperationException` from 20 (removal of `stop` follows). jdeprscan reports them. Replace with cooperative cancellation: `interrupt()` plus checks of `Thread.interrupted()`, or `Future.cancel(true)`.

## Dynamic agent loading — JEP 451 (21)

Agents attached at runtime (Mockito inline mock maker, Byte Buddy agent, some profilers and APMs) print a warning on 21 and will be denied by default in a future release.

- Tests: attach Mockito as `-javaagent` (java-build references). Do not just add `-XX:+EnableDynamicAgentLoading`.
- Production APM agents: start them with `-javaagent:` on the command line instead of self-attach.

## Sequenced collections — JEP 431 (21)

New default methods `getFirst`, `getLast`, `addFirst`, `addLast`, `removeFirst`, `removeLast`, `reversed` on `List`, `Deque`, `LinkedHashSet`, `SortedSet`, `LinkedHashMap` (`firstEntry`, `pollFirstEntry`, `putFirst`, `sequencedKeySet`, …).

Breaks compilation when a custom collection subclass already declares one of these names with an incompatible return type or throws clause (for example a `getFirst()` returning `Optional<T>`). Rename the custom method or align its signature.

## Biased locking removed — JEP 374 (15 disabled, 18 obsolete)

Drop `-XX:+UseBiasedLocking` and `-XX:BiasedLockingStartupDelay`.

## Other changes

- `java.lang.Compiler` removed (21); `ThreadGroup` destroy/daemon methods degraded.
- `URL` constructors deprecated (20): use `URI.create(s).toURL()`.
- Default `jdk.httpclient` and TLS tweaks: TLS 1.0/1.1 disabled by default (since 11.0.11/16); legacy servers need explicit configuration.
- Generational ZGC added in 21 behind `-XX:+UseZGC -XX:+ZGenerational`. That flag is valid only on 21–23; do not introduce it if the next hop is 25.
- Windows 32-bit x86 port deprecated (21).
- Preview features in 21 (string templates, unnamed classes, structured concurrency, scoped values): do not adopt; see `jdk-matrix.md`.
