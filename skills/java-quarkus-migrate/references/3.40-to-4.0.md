# Quarkus 3.40 → 4.0 (beta)

**BETA.** Based on 4.0.0.Beta3 and wiki Migration-Guide-4.0 at commit `4b6f152` (2026-11-08). Refresh this file at GA. Run this hop only when the user explicitly opted in to 4.0 in the plan.

- Stream: `--stream=4.0`, plugin `4.0.0.Beta3`. Not verified that the update tool offers the 4.0 stream before GA; if it does not, use `--platformVersion=4.0.0.Beta3` or stop and report
- JDK: 21 minimum (Java 17 no longer supported), 25 recommended. Run the JDK hop to 21 first if the project is below 21
- Major libraries: Hibernate ORM 7.4 → 8.0 (Jakarta Persistence 4.0), Hibernate Reactive 4.5 → 5.1, Hibernate Search 8.4 → 9.0, Jakarta REST 4.0 with RESTEasy 7, Vert.x 5, Jackson 2 → 3, Flyway 13.10, SmallRye Fault Tolerance 7.0, CDI 5.0
- Container images: UBI 10 by default
- Scan: `scan.sh <root> --framework quarkus --from 3.40 --to 4.0`

## Manual

### General and config

| Since | Change | Fix |
|-------|--------|-----|
| 4.0 | Config properties deprecated before 3.33 removed (full table in Migration-Guide-4.0 "Config") | Replace each with the listed replacement; some have none (`quarkus.hibernate-search-orm.automatic-indexing.enable-dirty-check`, `quarkus.rest.qute.template-instance-non-blocking-type`, `quarkus.transaction-manager.unsafe-multiple-last-resources`) (`removed-config-keys`) |

### REST and HTTP

| Since | Change | Fix |
|-------|--------|-----|
| 4.0 | `;` is no longer a query parameter delimiter: `a=1;b=2` is one parameter `a` | Use `&`, or set `quarkus.http.use-semicolon-as-query-param-delimiter=true` (`quarkus.management.…` for the management interface) |
| 4.0 | Jakarta REST 4 APIs, RESTEasy 7; Quarkus REST supports Jakarta REST 4 partially | Test REST endpoints fully |
| 4.0 | `SseEventSink.close()` throws `IOException` | Handle or declare `IOException` |
| 4.0 | Quarkus REST endpoints may no longer return a REST Client `Response` or `RestResponse` | Map the client response to a new server response |
| 4.0 | WebSockets Next `BasicWebSocketConnector` sends the base URI as given, no trailing slash added | Add the trailing slash if the server path needs it |

### gRPC

| Since | Change | Fix |
|-------|--------|-----|
| 4.0 | Separate gRPC server removed; services run on the HTTP server. Port 9000 is gone | Point clients at `${quarkus.http.port}` (`${quarkus.http.ssl-port}` for TLS) |
| 4.0 | `quarkus.grpc.server.port`, `quarkus.grpc.server.use-separate-server`, `quarkus.grpc.server.ssl.certificate`, `quarkus.grpc.server.ssl.key` removed | Use `quarkus.http.port`, `quarkus.http.ssl.certificate.files`, `quarkus.http.ssl.certificate.key-files`; certificates must be filesystem paths (`grpc-separate-server`) |

### Serialization

| Since | Change | Fix |
|-------|--------|-----|
| 4.0 | Quarkus produces a `JsonMapper` bean, not `ObjectMapper`. Injecting `ObjectMapper` still works | Fix programmatic CDI lookups by exact `ObjectMapper` type |
| 4.0 | `ObjectMapperCustomizer` → `JsonMapperBuilderCustomizer`, which receives a `JsonMapper.Builder`; new `JsonFactoryBuilderCustomizer` | Rewrite customizers to configure the builder (`object-mapper-customizer`) |
| 4.0 | Jackson 3 defaults: fail on trailing tokens, fail on null for primitives, no default view inclusion, no getters-as-setters. Quarkus keeps Jackson 2 defaults for `fail-on-empty-beans` and `write-durations-as-timestamps` | Revert per feature with `quarkus.jackson.fail-on-trailing-tokens`, `fail-on-null-for-primitives`, `default-view-inclusion`, `use-getters-as-setters` |
| 4.0 | Other Jackson 3 API changes | See the Jackson `MIGRATING_TO_JACKSON_3.md` guide |
| 4.0 | Avro 1.12.2 rejects untrusted classes on deserialization (`SecurityException`); Avro-generated and Protobuf classes are trusted | Trust others with `quarkus.avro.trusted-classes`/`trusted-packages` (build time); `@QuarkusIntegrationTest` test JVMs need `org.apache.avro.SERIALIZABLE_PACKAGES` |
| 4.0 | `quarkus-messaging-pulsar` pulls in `quarkus-avro` | No action unless the validator rejects classes |

### Persistence

| Since | Change | Fix |
|-------|--------|-----|
| 4.0 | Higher default database versions at build time: Db2 12.1, MariaDB 11.4, SQL Server 16, MySQL 8.4, Oracle 23, PostgreSQL 16. Older servers fail at startup | Upgrade the database, or set `quarkus.datasource.db-version` to the actual version |
| 4.0 | `quarkus.hibernate-orm.sql-load-script` deprecated; replaced by `schema-management.init-script` (`schema.sql`) and `data-management.init-script` (`data.sql`). `import.sql` next to `schema.sql`/`data.sql` fails the build | Split `import.sql` into `schema.sql`/`data.sql`; see the migration steps in the guide (`sql-load-script`) |
| 4.0 | `data.sql` runs whenever `data-management.strategy=create` (dev/test default), also with Flyway/Liquibase | Make it idempotent, or set `quarkus.hibernate-orm.data-management.strategy=none`; set `%prod…strategy=create` if prod relied on it |
| 4.0 | `quarkus.hibernate-orm.log-session-metrics` removed | Use log category `org.hibernate.session.metrics` at `DEBUG` |
| 4.0 | ORM 8: `Session.replicate()` and `ReplicationMode` removed | Consider `StatelessSession.upsert()` |
| 4.0 | ORM 8: `StatelessSession.insert()` returns no identifier; `fetch()` returns the fetched value | Adapt callers |
| 4.0 | ORM 8: mutation queries must use `@NamedStatement`/`@NamedNativeStatement`, not `@NamedQuery`/`@NamedNativeQuery` | Move update/delete named queries |
| 4.0 | ORM 8: `@GenericGenerator` with `name` or `strategy` changed | See ORM 8.0 migration guide, `generic-generator` |
| 4.0 | ORM 8: `org.hibernate.transform` removed | Use `TupleTransformer`, constructor expressions or `@ConstructorResult` |
| 4.0 | ORM 8: query result types checked more strictly | Fix projections or result classes |
| 4.0 | ORM 8: `@ManyToOne`/`@OneToOne` targets hidden by `@SQLRestriction` or `applyToLoadByKey` filters are nulled out | Review filtered associations |
| 4.0 | ORM 8: graph-based flushing may change SQL statement order | Review tests; temporary fallback `quarkus.hibernate-orm.unsupported-properties."hibernate.flush.queue.type"=legacy` |
| 4.0 | ORM 8: unique constraints on sets with nullable elements may change | Review generated DDL before applying |
| 4.0 | `java.time` direct JDBC binding stays off in Quarkus | Opt in with `quarkus.hibernate-orm.mapping.java-time.use-direct-jdbc=true` only after reading the ORM guide |
| 4.0 | Hibernate Reactive 5.1: query flush mode takes `jakarta.persistence.QueryFlushMode`; `get()` throws `EntityNotFoundException`; `currentTransaction()` sees external transactions | Use `QueryFlushMode.NO_FLUSH` etc.; use `find()` where `null` is expected |
| 4.0 | Hibernate Search 9: `Search.toJpaQuery()`/`toOrmQuery()` removed; automatic-indexing synchronization API removed; getter/constructor exceptions no longer wrapped the same way | Use the Search DSL; `indexingPlanSynchronizationStrategy(...)` and `IndexingPlanSynchronizationStrategy`. | 4.0 | Quarkus Data: `io.quarkus.data.hibernate.stateless` → `io.quarkus.data.hibernate.record`; `managedBlocking()` → `managed()`, `statelessBlocking()` → `record()`, `statelessReactive()` → `recordReactive()` | Rename imports and accessors; recompile with the processor for generated types |

### Extension developers

Deprecated core, bootstrap, devtools and ArC processor APIs were removed (`CodeGenProvider.inputExtension()`, `Capability.SMALLRYE_REACTIVE_MESSAGING`, `PackageTypeBuildItem`, `ExecUtil`, `MemorySize(BigInteger)`, `MemorySizeConverter`, `QuarkusBootstrap.builder(Path)`, `ArtifactKey.gac()`/`gact()`, `ObserverInfo.getId()`, …). Application code is rarely affected; see Migration-Guide-4.0 "For extension and Quarkus developers". New `AvroTrustedClassBuildItem` for extensions that deserialize classes through Avro.
