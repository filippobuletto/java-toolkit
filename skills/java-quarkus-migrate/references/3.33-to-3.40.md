# Quarkus 3.33 → 3.40

Covers wiki Migration-Guide-3.34 to 3.40 (commit `4b6f152`). 3.40 is the LTS continuation of 3.39 and adds no changes of its own.

- Stream: `--stream=3.40`, plugin `3.40.1.1`
- JDK: 17 minimum (unchanged), 25 recommended
- Major libraries: Hibernate ORM 7.2 → 7.4, Hibernate Reactive 3.4, Hibernate Search 8.4, REST Assured 6.0
- Scan: `scan.sh <root> --framework quarkus --from 3.33 --to 3.40`

## Automated (verify)

`quarkus update` handles these. Check the diff did them.

| Since | Item | Check |
|-------|------|-------|
| 3.37 | Panache Next renamed to Quarkus Data: `quarkus-hibernate-panache-next*` → `quarkus-data-hibernate*` | no `panache-next` artifact left (`panache-next` signal) |
| 3.39 | Quarkus Data packages: `io.quarkus.hibernate.panache` → `io.quarkus.data.hibernate`; `PanacheEntity` split into `ManagedEntity` and `RecordEntity` (`.Reactive`, `.CustomId` variants); `PanacheQuery` → `DataQuery`; annotation processor `hibernate-jpamodelgen` → `io.quarkus:quarkus-data-processor` | build compiles; processor swapped in the build file |

Panache Next and Quarkus Data are experimental. Classic Panache, `quarkus-hibernate-orm-panache`, is not renamed.

## Manual

### REST and HTTP

| Since | Change | Fix |
|-------|--------|-----|
| 3.35 | `@Transactional` endpoints are no longer forced onto a worker thread. The return type decides: `Uni<T>` runs on the event loop | Add `@Blocking` to `@Transactional` methods that return `Uni` and block (`transactional-uni`) |
| 3.35 | Management interface CORS is off unless configured | Set `quarkus.management.cors.enabled=true` and `quarkus.management.cors.origins=…` if another origin calls it |
| 3.38 | When `quarkus.http.host` is `localhost`, `127.0.0.1` or `[::1]`, requests whose `Host` header is not a localhost name get `400` in dev and prod | Behind a proxy that forwards `Host`: set `quarkus.http.host-validation.allowed-hosts`, or `quarkus.http.host-validation.require-localhost=false` (`http-host-localhost`) |
| 3.38 | `FileUpload#fileName()` is sanitized: path parts and null bytes stripped, `null` for empty, `.` or `..`. No property restores the old value | Handle `null`; send directory structure in a separate form field (`fileupload-filename`) |
| 3.38 | REST Assured base path now includes `quarkus.servlet.context-path` | Drop the context path from test URLs that added it by hand |

### Persistence

| Since | Change | Fix |
|-------|--------|-----|
| 3.35 | Hibernate ORM 7.3: obsolete `@Columns` annotation removed | Follow the ORM 7.3 migration guide, section `columns-annotation` |
| 3.35 | Collections of read-only entities are read-only; modifying them fails | Load the owner as writable before changing the collection |
| 3.35 | `getSingleResult()` and `getSingleResultOrNull()` always throw on more than one row | Fix the query, or use `getResultList()` |
| 3.35 | Timeouts that mark the transaction for rollback throw `PersistenceException`, not `QueryTimeoutException`/`LockTimeoutException` | Catch `PersistenceException` where the old types were caught |
| 3.35 | `@Version` columns are `not null` in generated DDL | Migrate existing nullable version columns |
| 3.35 | CockroachDB minimum 23.2 | Upgrade the database, or set `quarkus.datasource.db-version` |
| 3.37 | Hibernate ORM 7.4: Oracle HQL `current date`/`local date` → `trunc(current_date)` | Review date comparisons on Oracle |
| 3.37 | MySQL has no dialect default for `quarkus.hibernate-orm.fetch.max-depth` (was 2) | Set it explicitly if the app relied on 2 |
| 3.37 | Limit/pagination with collection fetch runs in SQL | Query hint `org.hibernate.limitInMemory` restores the old behavior |
| 3.37 | Schema actions and `import.sql` run even with no `@Entity` | Remove stray `import.sql` files from the classpath |
| 3.37 | `SpannerPostgreSQLDialect` moved to `org.hibernate.dialect` in `hibernate-core` | Update an explicit dialect setting |
| 3.37 | DDL adds unique constraints on `@ElementCollection` set tables and `NOT NULL` on `@CreationTimestamp`/`@UpdateTimestamp` | Migrate existing schemas (Flyway/Liquibase) |
| 3.37 | PostgreSQL minimum 14 | Upgrade the database, or set `quarkus.datasource.db-version` |

Hibernate Reactive 3.3/3.4 and Hibernate Search 8.3/8.4 add nothing beyond the ORM items. Search needs no reindexing.
