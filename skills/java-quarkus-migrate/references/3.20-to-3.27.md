# Quarkus 3.20 → 3.27

Covers wiki Migration-Guide-3.21 to 3.27 (commit `4b6f152`). 3.27 is the LTS continuation of 3.26 and adds no changes of its own.

- Stream: `--stream=3.27`, plugin `3.27.6.1`
- JDK: 17 minimum (unchanged), 21 recommended
- Major libraries: Hibernate ORM 6.6 → 7.0 (3.24, Jakarta Persistence 3.2) → 7.1 (3.26), Hibernate Reactive 3.0/3.1, Hibernate Search 8.0/8.1, Elasticsearch Dev Services 9.0, OpenSearch Dev Services 3.0
- Scan: `scan.sh <root> --framework quarkus --from 3.20 --to 3.27`

Hibernate ORM 7 is the largest change in this hop. Read the ORM 7.0 migration guide (<https://docs.jboss.org/hibernate/orm/7.0/migration-guide/migration-guide.html>) alongside this file.

## Manual

### Persistence: Hibernate ORM 7

| Since | Change | Fix |
|-------|--------|-----|
| 3.24 | `Session#update`, `load` with lock, `saveOrUpdate` removed or deprecated | `update` → `merge`, `load` with lock → `find`, `saveOrUpdate` → `persist` (new) or `merge` (detached). Use the entity `merge` returns; preload with `Session#findMultiple` to avoid N+1 (`hibernate-orm-7`) |
| 3.24 | Deprecated annotations removed: Hibernate `@Table`, `@Where`/`@WhereJoinTable`, `@OrderBy`, `@Index`, `@IndexColumn` | `@jakarta.persistence.Table`, `@SQLRestriction`/`@SQLJoinTableRestriction`, `@SQLOrder` or `@jakarta.persistence.OrderBy`, `@jakarta.persistence.Index`, `@OrderColumn` (`orm-removed-annotations`) |
| 3.24 | Proxy customization changed | Replace `@Proxy` with `@ConcreteProxy`, or use `Session#getReference`/`Hibernate#unproxy` |
| 3.24 | `org.hibernate.Metamodel` removed | Use `org.hibernate.metamodel.model.domain.JpaMetamodel` |
| 3.24 | `UserType` and `CompositeType` method signatures changed; several JDBC types moved to an internal package | Update implementations; map with `@JdbcTypeCode` instead of `@JdbcType` |
| 3.24 | `LockOptions` deprecated (3.26 / ORM 7.1 removes some features) | Use the `LockMode` alternatives |
| 3.24 | Misplaced mapping annotations throw (conflicting `@Basic`/`@ManyToOne`, converters on `@Id`/`@Version`/associations) | Remove the conflicting annotations |
| 3.24 | `StatelessSession` uses the second-level cache and ignores `quarkus.hibernate-orm.jdbc.statement-batch-size` | Use explicit batch operations such as `insertMultiple()` |
| 3.24 | Ambiguous query strings rejected: no `select` clause plus a non-fetch join (common in Panache) | `from Person p left join p.address` → `from Person p`, `select p, a from Person p left join p.address a`, or a `join fetch` |
| 3.24 | Native queries return `java.time` types instead of `java.sql` for dates | Update result handling |
| 3.24 | Quoting regression from ORM 6 fixed | Adapt custom init scripts (H2 in particular) that relied on quotes |
| 3.24 | Basic arrays (`String[]`) map to real array columns on DB2, SAP HANA, SQL Server, Sybase ASE | Migrate schema and data, or set `quarkus.hibernate-orm.unsupported-properties."hibernate.type.preferred_array_jdbc_type"=VARBINARY` |
| 3.24 | `char` → `varchar(1)`; Oracle/SQL Server timestamp precision; Oracle `float`/`double` → `binary_float`/`binary_double` | New DDL only; existing schemas keep working |
| 3.24 | Annotation processor moved: `org.hibernate.orm:hibernate-jpamodelgen` → `org.hibernate.orm:hibernate-processor`; `JPAMetaModelEntityProcessor` → `org.hibernate.processor.HibernateProcessor` | Update `annotationProcessorPaths` (Maven) or `annotationProcessor` (Gradle) and explicit processor names (`hibernate-jpamodelgen`) |
| 3.24 | `JdbcType`, `JavaType`, `UserType`, `CompositeUserType`, `Generator`/`IdentifierGenerator`, `RevisionListener` and similar components can no longer be CDI beans | Look beans up lazily with `Arc.container().instance(OtherBean.class).get()` |
| 3.24 | Minimum database versions raised to the oldest vendor-supported version | Check the ORM 7.0 dialect page |
| 3.24 | Hibernate Reactive 3.0: `ReactiveIdentifierGenerator` API changed | Rewrite custom generators |
| 3.25 | Database version check handles Azure SQL Server and CockroachDB correctly; Hibernate Reactive now checks too | Set `quarkus.datasource.db-version` to the real server version (CockroachDB version, not PostgreSQL) |
| 3.26 | ORM 7.1: `Session#getLobHelper` deprecated | Use `Hibernate#getLobHelper` |
| 3.26 | Minimum DB2 11.1, MariaDB 10.6, SQL Server 12.0 (2014) | Upgrade the database, or set `quarkus.datasource.db-version` |
| 3.26 | Startup fails when JSON/XML is stored in the database and REST-layer JSON/XML serialization is customized | If the customization does not affect stored data, set `quarkus.hibernate-orm.mapping.format.global=ignore`; otherwise add a delegating `@JsonFormat`/`@XmlFormat` `FormatMapper` (Migration-Guide-3.26 "JSON/XML mapping") |
| 3.26 | `quarkus.hibernate-orm.dialect.storage-engine` deprecated | Use `quarkus.hibernate-orm.dialect.mysql.storage-engine` or `.mariadb.storage-engine` |
| 3.22 | Hibernate Reactive apps with an extra named JDBC datasource now get Hibernate ORM enabled, which needs a datasource | Set `quarkus.hibernate-orm.blocking=false`, or `quarkus.hibernate-orm.datasource` |
| 3.22 | REST Data Panache modules work only with `quarkus-rest*`, not `quarkus-resteasy*` | Move to Quarkus REST |
| 3.22 | `QuarkusTransaction.isActive()` deprecated | Use `QuarkusTransaction.getStatus()` |
