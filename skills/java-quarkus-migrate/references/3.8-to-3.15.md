# Quarkus 3.8 → 3.15

Covers wiki Migration-Guide-3.9 to 3.15 (commit `4b6f152`). 3.15 is the LTS continuation of 3.14 and adds no changes of its own.

- Stream: `--stream=3.15`, plugin `3.15.7`
- JDK: 17 minimum (unchanged), 21 recommended
- Major libraries: Hibernate ORM 6.4 → 6.6, Hibernate Search 7.1, Flyway 10, Infinispan 15, Micrometer 1.13, MongoDB client 5.1, OpenTelemetry SDK 1.39 / instrumentation 2.5
- Scan: `scan.sh <root> --framework quarkus --from 3.8 --to 3.15`

## Manual

### REST and HTTP

| Since | Change | Fix |
|-------|--------|-----|
| 3.9 | JAX-RS filters run only on JAX-RS resources, not on other paths | Add an `ExceptionMapper<NotFoundException>` if filters must run on not-found paths |
| 3.9 | HAL wrappers are generic: `HalCollectionWrapper<T>`, `HalEntityWrapper<T>` | Add type arguments; prefer `HalService.toHalCollectionWrapper(...)` / `toHalWrapper(...)` |
| 3.9 | JKS is no longer the default key/trust store format; the format is guessed from the file extension (`.jks`, `.p12`, `.pem`, …) | Set `quarkus.http.ssl.certificate.key-store-file-type` / `trust-store-file-type` for other extensions |
| 3.10 | Quarkus REST methods returning `TemplateInstance` are blocking by default | Add `@NonBlocking` to restore event-loop execution |
| 3.10 | Injecting `quarkus.oidc.UserInfo` sets `quarkus.oidc.authentication.user-info-required=true` | For tenants without UserInfo set `quarkus.oidc.<tenant>.authentication.user-info-required=false` |

### Persistence

| Since | Change | Fix |
|-------|--------|-----|
| 3.9 | Several non-XA datasources in one transaction now fail (`Failed to enlist…`) | See the datasource guide section on multiple datasources in a single transaction |
| 3.11 | Hibernate ORM 6.5 tightens checks: wrong config, mapping or queries can now throw | ORM 6.5 migration guide |
| 3.12 | Startup fails when the database is older than the build-time default version: DB2 < 10.5, Derby < 10.15.2, Oracle < 19, MariaDB < 10.6, SQL Server < 13 (2016), MySQL < 8.0, PostgreSQL < 12 | Upgrade the database, or set `quarkus.datasource.db-version` (and the dialect if needed) |
| 3.13 | Auto-flush before queries only when pending changes affect the result | Check native queries; from 3.14.4 `quarkus.hibernate-orm.flush.mode=always` restores the old behavior |
| 3.14 | ORM 6.6: `merge` of an entity with a set `@GeneratedValue` id or `@Version` now fails instead of inserting | ORM 6.6 migration guide, merge-versioned-deleted |
| 3.14 | `@MappedSuperclass` and `@Embeddable` on the same type not allowed | Pick one |
| 3.14 | `@Embeddable` subtypes use discriminator-based inheritance by default | ORM 6.6 migration guide, embeddable-inheritance |
| 3.14 | `Expression#as(Class)` is an unchecked cast | Use `JpaExpression#cast(Class)` for a checked cast |
| 3.9 | Hibernate Search outbox-polling system tables may need a schema change | Migrate per Hibernate Search 7.1 guide, or set `…coordination.entity-mapping.{agent,outbox-event}.uuid-type=char` |
| 3.12 | Spring Data JPA layer aligned with Spring Data 3: `PagingAndSortingRepository` no longer extends `CrudRepository`; `ListCrudRepository`, `ListPagingAndSortingRepository` added | Repositories extending only `PagingAndSortingRepository` lose CRUD methods; `JpaRepository` extends both |

### Messaging and clients

| Since | Change | Fix |

| 3.12 | Mailer with STARTTLS must set `quarkus.mailer.tls=false` explicitly | Add it (and `quarkus.mailer.<name>.tls=false` for named mailers) |
| 3.13 | Redis `jsonMget()` takes `path` first, as declared | Fix call sites that passed the path last |
| 3.14 | MongoDB client 4.11 → 5.1 | Check the MongoDB driver 5 upgrade notes |
