# Quarkus 3.2 → 3.8

Covers wiki Migration-Guide-3.3 to 3.8 (commit `4b6f152`). 3.8 is the LTS continuation of 3.7.

- JDK: **17 minimum from 3.7**. Switch the project to JDK 17 (java-upgrade hop) before this hop starts; 3.2 still runs on 11. 21 recommended
- Stream: `--stream=3.8`, plugin `3.8.6.1`
- Major libraries: Hibernate ORM 6.2 → 6.4, Hibernate Search 6.2 → 7.0, Flyway 9.20
- Scan: `scan.sh <root> --framework quarkus --from 3.2 --to 3.8`

## Automated (verify)

`quarkus update` handles these. Check the diff did them.

| Since | Item | Check |

## Manual

### JDK and build

| Since | Change | Fix |
|-------|--------|-----|
| 3.7 | Java 17 minimum to build and run | Run the JDK 11 → 17 hop first (java-upgrade), including CI and container images |
| 3.3 | GraalVM API classes come from `org.graalvm.sdk:graal-sdk`, now `provided` and not transitive | Add it yourself if the app has GraalVM substitutions (version from the BOM) |
| 3.7 | Okhttp and Okio versions no longer managed by the BOM | Set their versions in the build file |
| 3.8.3 | GraalVM JavaScript polyglot: `org.graalvm.js:js` is not replaced by the recipe | Use `org.graalvm.polyglot:js-community` (CE) or `org.graalvm.polyglot:js` (EE) |
| 3.8.3 | Qute templates missing from native images built on Windows | `quarkus.native.resources.includes=**/*.html` (or matching glob) |

### Config

| Since | Change | Fix |
|-------|--------|-----|
| 3.4 | Vert.x HTTP config classes (for example `HttpConfiguration`) are `@ConfigMapping` interfaces | Extension code: call accessor methods (`field()`) instead of fields |
| 3.5 | Kubernetes env vars for config must use upper case with underscores; lowercase dotted names no longer work | Rename env vars per the config reference |
| 3.5 | Startup fails if a config value injected during static init (native build) differs at runtime | Annotate the injection point with `@io.quarkus.runtime.annotations.StaticInitSafe` when that is safe |
| 3.7 | Stork `stork."service".load-balancer` and `quarkus.stork."service".load-balancer` are ignored | Use `quarkus.stork."service".load-balancer.type` |

### Persistence

| Since | Change | Fix |
|-------|--------|-----|
| 3.3 | Flyway 9.20 moves Oracle support to a separate dependency | Add the Flyway Oracle dependency (see the Flyway extension guide) |
| 3.4 | Flyway regressions with several datasources | `quarkus.flyway.enabled=false`, or `quarkus.flyway."ds".active=false` per datasource |
| 3.7 | Hibernate ORM 6.4: support for some older database versions dropped | Check the 6.4 dialect page; upgrade the database or set `quarkus.datasource.db-version` |
| 3.7 | HQL `!=`/`<>` no longer compare against `null` | Use `is null` / `is not null` |
| 3.7 | HQL numeric literals typed as in Jakarta Persistence 3.2 | Review arithmetic and comparisons in queries (ORM 6.3 migration guide) |

### Hibernate Search

| Since | Change | Fix |
|-------|--------|-----|
| 3.3 | Hibernate Search 6.2: geo-point fields with default `projectable` (and default or `Sortable.NO` sortable) fail Elasticsearch schema validation | Add `projectable = Projectable.NO`, or recreate indexes and reindex (`MassIndexer` with `dropAndCreateSchemaOnStart(true)`) |
| 3.3 | Outbox-polling table schema changed | Migrate per Hibernate Search 6.2 migration guide, data-format section |
| 3.3 | `quarkus.hibernate-search-orm.automatic-indexing.synchronization.strategy` deprecated; `…automatic-indexing.enable-dirty-check` deprecated with no replacement | Use `quarkus.hibernate-search-orm.indexing.plan.synchronization.strategy`; drop the dirty-check key |
| 3.7 | Hibernate Search 7.0: `uuid-binary`/`uuid-char` values deprecated for `…coordination.entity-mapping.{outbox-event,agent}.uuid-type` | Use `binary` / `char` |
| 3.7 | `quarkus.hibernate-search-orm.elasticsearch.query.shard-failure.ignore` defaults to `false`: shard failures throw | Set it to `true` per backend to keep the old behavior |
| 3.7 | Regexp predicate complement operator `~` removed, no replacement | Rewrite those queries |
| 3.7 | Dependencies lose the `-orm6` suffix (`hibernate-search-mapper-orm-orm6` → `hibernate-search-mapper-orm`) | Rename explicit Hibernate Search dependencies |
| 3.7 | Outbox-polling system tables changed again | Migrate per Hibernate Search 7.0 migration guide, outboxpolling section |

### REST, HTTP and security

| Since | Change | Fix |
|-------|--------|-----|
| 3.6 | SmallRye JWT no longer brings `quarkus-reactive-routes` | Add `quarkus-reactive-routes` if used |
| 3.7 | Plain HTTP port disabled when `quarkus.http.ssl.client-auth=required` | Use `client-auth=request`, or `quarkus.http.insecure-requests=enabled` |
| 3.7 | OIDC tenant resolution through CDI annotations/interceptors no longer works on RESTEasy Classic | Use `@io.quarkus.oidc.Tenant` |
| 3.8.1 | Vert.x TCP clients (`Vertx.createNetClient()`) must set the hostname verification algorithm for TLS | Set it explicitly; `NONE` (config) or `""` (code) keeps the old, unverified behavior |
| 3.3 | Keycloak Authorization no longer brings `org.keycloak:keycloak-adapter-core` | Add the dependency if the app uses it |

### Clients and messaging

| Since | Change | Fix |
|-------|--------|-----|
| 3.3 | Elasticsearch High-Level Client extension removed | Move to the Elasticsearch Java Client |
| 3.6 | Strimzi OAuth 0.14.0 breaks Kafka native builds (`Substitution target … DefaultsImpl is not loaded`) | Add `io.strimzi:kafka-oauth-common` |
| 3.7 | Infinispan `quarkus-test-infinispan-client` retired | Use Infinispan Dev Services |
| 3.5 | OptaPlanner extensions removed from the platform | Move to Timefold extensions |

### Templates and GraphQL

| Since | Change | Fix |
|-------|--------|-----|
| 3.4 | GraphQL directive annotations only apply where their `on` declaration allows | Check directive placements |
| 3.5 | Qute user tags run isolated (no access to the caller's context) | Add `_isolated=false` or `_unisolated` at the call site |
| 3.5 | Qute `ResultNode` is an abstract class | Extend instead of implement |
| 3.5 | Qute accepts only `CompletableFuture` and `CompletedStage` | `-Dquarkus.qute.unrestricted-completion-stage-support=true` restores any `CompletionStage` |

### Observability

| Since | Change | Fix |
|-------|--------|-----|
| 3.3 | OTel exporter is a Vert.x-based Quarkus implementation (no OkHttp); `quarkus.otel.traces.exporter` defaults to `cdi`; protocol `grpc` default | Set `quarkus.otel.exporter.otlp.traces.protocol=http/protobuf` if the collector needs it |
| 3.3 | `quarkus.tls.trust-all=true` also disables TLS verification on the OTel exporter | Do not rely on trust-all in production |
| 3.7 | All scheduled jobs (also programmatic) get a span; span name is the job identity, not `<class>.<method>` | Update dashboards and alerts keyed on span names |

### Deployment

| Since | Change | Fix |
|-------|--------|-----|
| 3.7 | OpenShift default deployment kind is `Deployment`; redeploying leaves the old `DeploymentConfig` running | Delete the old `DeploymentConfig`, or set `quarkus.openshift.deployment-kind=DeploymentConfig`; consider `quarkus.openshift.add-version-to-label-selectors=false` before the switch |

### Testing and Dev Services

| Since | Change | Fix |
|-------|--------|-----|
| 3.3, 3.4 | Elasticsearch Dev Services start 8.x (8.9 in 3.4); OpenSearch is started when the extension expects it | Configure the image explicitly to pin a distribution or version |
| 3.4 | `QuarkusComponentTestExtension` is immutable; with `PER_CLASS` lifecycle the container starts in `before all`, else per method | Build it with `QuarkusComponentTestExtension(Class...)` or `.builder()`; check lifecycle-dependent tests |
| 3.5 | SQL Server Dev Services use `2022-latest` (`azure-sql-edge:latest` on Apple silicon) | Update `container-license-acceptance.txt` |
