# Quarkus 3.15 → 3.20

Covers wiki Migration-Guide-3.16 to 3.20 (commit `4b6f152`). 3.20 is the LTS continuation of 3.19 and adds no changes of its own.

- Stream: `--stream=3.20`, plugin `3.20.6.2`
- JDK: 17 minimum (unchanged), 21 recommended
- Major libraries: Hibernate ORM 6.6, Flyway 11, Fabric8 Kubernetes Client 7.0, SmallRye Fault Tolerance 6.7, OpenTelemetry SDK 1.44.1, BouncyCastle 1.80
- Scan: `scan.sh <root> --framework quarkus --from 3.15 --to 3.20`

## Automated (verify)

`quarkus update` handles these. Check the diff did them.

| Since | Item | Check |
|-------|------|-------|
| 3.19 | `quarkus.http.cors` → `quarkus.http.cors.enabled`; `quarkus.log.{console,file,syslog,socket}.json` → `quarkus.log.*.json.enabled` | no bare `quarkus.http.cors=` or `quarkus.log.*.json=` key left |

## Manual

### Build and artifacts

| Since | Change | Fix |
|-------|--------|-----|
| 3.16 | Maven relocations and config fallbacks from the 3.9 rename are gone: old `quarkus-resteasy-reactive*`, `quarkus-rest-client-reactive*` artifacts and config roots no longer resolve | Switch to the 3.9 names (`rest-reactive-artifact`, `rest-reactive-config`); see Migration-Guide-3.9 |
| 3.17 | OpenTracing removed, including its BOM entries | Move to OpenTelemetry (guide `telemetry-opentracing-to-otel-tutorial`) (`opentracing`) |
| 3.18 | `io.quarkus:quarkus-test-openshift-client` removed (Fabric8 7.0) | Use `io.quarkus:quarkus-test-kubernetes-client`; moved model classes: Fabric8 MIGRATION-v7.md |
| 3.19 | Quarkiverse Micrometer Registry extensions need `3.3.0` | Bump them to 3.3.0 |
| 3.19 | BouncyCastle 1.80 | Add `org.bouncycastle:bcutil-jdk18on` if older-BC code breaks |
| 3.19 | Builder and runtime images default to UBI 9 | In-container native builds need a UBI 9 runtime image; UBI 8 image names are in Migration-Guide-3.19 "UBI 9" |

### REST and HTTP

| Since | Change | Fix |
|-------|--------|-----|
| 3.16 | `quarkus.http.compress-media-types` default now includes `application/json` and `application/xhtml+xml` | Set the property if responses must stay uncompressed |
| 3.16 | WebSockets Next: unhandled failures are logged, and server connections closed (was closed silently) | Set `quarkus.websockets-next.server.unhandled-failure-strategy` to change it |
| 3.16 | WebSockets Next `HttpUpgradeContext` takes `Uni<SecurityIdentity>` | Update code that constructs it |
| 3.17 | REST Client config: `[SimpleClassName]/mp-rest` no longer works; legacy `quarkus.rest.client.max-redirects` and `quarkus.rest.client.multipart-post-encoder-mode` removed | Use `FQCN/mp-rest` or `quarkus.rest-client."FQCN".*` keys |
| 3.18 | Empty query parameter (`?foo=`) gives `null` for `@RestQuery String` and an empty list for `@RestQuery List<String>` (was `""`) | Handle `null` |
| 3.18 | Management interface listens on `localhost` in dev and test (was `0.0.0.0`) | Configure the host if dev/test tools reach it remotely |

### Persistence

| Since | Change | Fix |
|-------|--------|-----|
| 3.16 | `quarkus.datasource.jdbc.tracing` deprecated for removal | Use `quarkus.datasource.jdbc.telemetry=true` |
| 3.16 | MongoDB with Panache adds the square brackets around list parameters: `{'status':{$in: ?1}}` | Remove hand-written brackets around `?n` in `$in` queries |
| 3.17 | Reactive datasources have no default `localhost` URL outside Dev Services; without a URL the datasource is deactivated | Set `quarkus.datasource.reactive.url` explicitly |
| 3.17 | Datasources without a URL contribute no health check | Set the URL if the health check is needed |
| 3.17 | Injecting a deactivated or URL-less `DataSource`, `Pool`, `Flyway` or `LiquibaseFactory` fails at startup (`InactiveBeanException`) | Inject `InjectableInstance<…>` and check `getHandle().getBean().isActive()`, or follow the exception message |
| 3.18 | Flyway 11 removes `cleanOnValidationError` | 3.18.2+: `quarkus.flyway.validate-at-start.clean-on-validation-error` (only for validate-at-start) |
| 3.18 | IBM Db2 driver and Dev Services image 12 | License registration changed: see the IBM link in Migration-Guide-3.18 "IBM Db2" |
| 3.19 | Bean Validation constraints now shape generated DDL | `quarkus.hibernate-orm.validation.mode=callback` keeps the old behavior; `validation.enabled` is deprecated, use `validation.mode=none` |

### Serialization and templates

| Since | Change | Fix |
|-------|--------|-----|
| 3.18 | Only unqualified `ObjectMapperCustomizer` beans apply to the default `ObjectMapper` | Remove qualifiers from customizers meant for the default mapper |
| 3.18 | Qute JSON templates escape `"`, `\` and control characters | Use `raw`/`safe` or `RawString` for unescaped output |

### Security

| Since | Change | Fix |
|-------|--------|-----|
| 3.16 | `quarkus.oidc.tls.*` and `quarkus.oidc-client.tls.*` store properties deprecated | Point `quarkus.oidc.tls.tls-configuration-name` at a TLS registry config |
| 3.16 | OIDC Client without a URL starts Keycloak Dev Services in dev mode | Disable with `quarkus.keycloak.devservices.enabled` |
| 3.18 | `quarkus-security-webauthn` rebuilt on WebAuthn4J: not source or binary compatible. `Authenticator` → `WebAuthnCredentialRecord`, `WebAuthnUserProvider` methods renamed, endpoints renamed and disabled by default, config keys renamed (`origin` → `origins`, `pub-key-cred-params` → `public-key-credential-parameters`, `require-resident-key` → `resident-key`), `user-verification` default `REQUIRED` | Work through Migration-Guide-3.18 "WebAuthn"; migrate stored credential data |

### Fault tolerance, scheduling and CDI config

| Since | Change | Fix |
|-------|--------|-----|
| 3.16 | `Fallback/fallbackMethod` and `BeforeRetry/methodName` config is read at build time | Do not override them at runtime |
| 3.17 | `Scheduler` methods throw `UnsupportedOperationException` when the scheduler is not started | Check `Scheduler#isStarted()` first |
| 3.18 | SmallRye Fault Tolerance programmatic API v1 (`FaultTolerance`, `@ApplyFaultTolerance`) deprecated | Move to `Guard`, `TypedGuard`, `@ApplyGuard` |
| 3.19 | Quarkus config classes are `@ConfigMapping` interfaces; `GlobalDevServicesConfig`, `HttpConfiguration`, `HttpBuildTimeConfig` kept as deprecated shims | Extension code: use `DevServicesConfig`, `VertxHttpConfig`, `VertxHttpBuildTimeConfig` |

### Observability

### Testing and native

| 3.16 | `@WithTestResource(restrictToAnnotatedClass)` replaced by `scope` | Use `scope` |
